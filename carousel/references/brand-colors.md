# Brand Color Reference

Use a featured company/tool's real brand identity. This list covers common
AI/dev tools; if the topic isn't listed, look up the tool's actual brand
colors (site header, logo, official brand page) rather than guessing.

| Brand | Palette |
|---|---|
| Anthropic / Claude | Cream, orange, dark gray/charcoal |
| OpenAI | White, black |
| Cursor | Black, purple |
| Vercel | Black, white |
| Supabase | Green, dark |
| Figma | White, red, blue, green |
| Linear | Near-black, indigo/violet accent |
| Stripe | Deep indigo/violet gradient, white |
| Notion | White, black, soft pastel accents |

Rules:
- Two-to-three color max per slide (a primary, a neutral, one accent).
- Never mix an unrelated brand's palette into a post about a different tool.
- If the topic is generic (e.g. "AI trends 2026", not tied to one brand), pick
  a clean neutral palette (off-white/charcoal/one accent) rather than
  defaulting to Anthropic's palette by habit.
